### Алгоритм решения
Вспомогательный алгоритм: Нормализация времени
1. Проверить значение минут на отрицательность (возникает при вычитании). Пока минуты меньше нуля: вычесть 1 из часов и прибавить 60 к минутам
2. Проверить избыток минут (возникает при сложении). Прибавить к часам результат целочисленного деления минут на 60, а в поле минут записать остаток от деления на 60
3. Проверить значение часов на отрицательность (переход в предыдущие сутки). Пока часы меньше нуля: прибавлять 24 к часам до получения положительного значения
4. Проверить избыток часов (переход в следующие сутки). Записать в поле часов остаток от деления текущего значения часов на 24

Алгоритм вычитания времени
1. Принять на вход два объекта: уменьшаемое (поля текущего объекта) и вычитаемое (переданный аргумент).
2. Создать новый пустой результирующий объект.
3. Вычислить часы результата как разность часов уменьшаемого и вычитаемого.
4. Вычислить минуты результата как разность минут уменьшаемого и вычитаемого.
5. Применить к результирующему объекту алгоритм нормализации времени для корректной обработки возможных отрицательных значений.
6. Вернуть результирующий объект.

# Задание 2
## Задача 14

### Текст задачи
В задании 2 добавить к реализованному в первом задании классу указанные в варианте
перегруженные операции
<img width="1200" height="291" alt="image" src="https://github.com/user-attachments/assets/48e13fbd-19a4-4e31-bafb-479f4e60183d" />

### Алгоритм решения
Алгоритм унарной операции: Префиксный декремент (--t)
1. Уменьшить значение поля минут текущего объекта на 1
2. Вызвать алгоритм нормализации для текущего объекта (на случай, если минуты стали равны -1)
3. Вернуть ссылку на измененный текущий объект

Алгоритм унарной операции: Постфиксный декремент (t--)
1. Создать временную копию текущего объекта для сохранения его начального состояния
2. Вызвать операцию префиксного декремента для текущего объекта, чтобы уменьшить его время
3. Вернуть сохраненную временную копию (таким образом, в месте вызова возвращается старое значение, а сам объект изменяется)

Алгоритмы операций приведения типа
1. Для явного приведения к short int: получить доступ к полю часов текущего объекта и вернуть это значение (минуты при этом игнорируются и отбрасываются)
2. Для неявного приведения к bool: проверить логическое условие «часы не равны нулю ИЛИ минуты не равны нулю». Если условие истинно, вернуть true, в противном случае вернуть false

Алгоритм бинарной операции: Сложение времени с минутами
1. Принять на вход текущий объект времени и беззнаковое целое число (добавляемые минуты)
2. Создать новый результирующий объект, скопировав в него часы текущего объекта
3. Вычислить минуты результирующего объекта как сумму минут текущего объекта и переданного числа
4. Вызвать алгоритм нормализации для результирующего объекта (чтобы перевести избыток минут в часы)
5. Вернуть результирующий объект

Алгоритм бинарной операции: Сложение двух времен
1. Принять на вход два объекта времени (первое и второе слагаемые)
2. Создать новый результирующий объект
3. Записать в его поле часов алгебраическую сумму часов обоих объектов
4. Записать в его поле минут алгебраическую сумму минут обоих объектов
5. Вызвать алгоритм нормализации для результирующего объекта
6. Вернуть результирующий объект
