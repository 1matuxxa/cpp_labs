### Текст задачи

Ввод: 1 2 3 4 5 6
Результат: 4 5 6 1 2 3

### Алгоритм решения

1. Считать количество элементов и сами элементы в вектор V, используя итераторы и конструктор (например, через istream_iterator или ввод в цикле).

3. Вывести элементы от mid до V.end() в прямом порядке.
4. Вывести элементы от V.begin() до mid в прямом порядке.

Вставить после элемента списка с порядковым номером 5 первые 5 элементов вектора в обратном порядке.

3. В качестве диапазона для вставки использовать обратные итераторы вектора V: от make_reverse_iterator(V.begin() + 5) до make_reverse_iterator(V.begin()). Это вставит первые 5 элементов в обратном порядке.

# Задание 3. Удаление элементов

## Задача 3. Удаление четных элементов в первой половине дека

### Текст задачи

Дан дек D с количеством элементов, кратным 4.
Удалить в первой половине исходного дека все элементы с четными порядковыми номерами (считая, что начальный элемент дека имеет порядковый номер 1).
Использовать функцию-член erase в цикле с числовым параметром.

### Алгоритм решения

1. Запомнить исходный размер дека: std::size_t n = D.size();.
2. Связать вспомогательный итератор с началом дека: auto i = D.begin();.
3. Запустить цикл, который выполнится n / 4 раз (именно столько четных элементов в первой половине).
4. В цикле выполнять i = D.erase(++i);. Инкремент ++i перешагивает через нечетный элемент, erase удаляет четный, а возвращаемое значение (следующий элемент) снова присваивается i.

3. Вызвать std::remove_copy_if с итератором вывода std::ostream_iterator<double>(std::cout, " "), чтобы сразу печатать результат в консоль через пробел.

## Задача 5. Вставка нулей после отрицательного и перед положительным

### Текст задачи

Дан список L, содержащий как отрицательные, так и положительные элементы.
Вставить нулевой элемент после первого отрицательного элемента и перед последним положительным элементом.
Использовать два вызова алгоритма find_if и два вызова функции-члена insert.

### Алгоритм решения

1. Найти первый отрицательный элемент с помощью std::find_if (предикат x < 0). Итератор itNeg.
2. Найти последний положительный элемент с помощью std::find_if с обратными итераторами L.rbegin(), L.rend() (предикат x > 0). Итератор rPos.
3. Вставить ноль после первого отрицательного: L.insert(std::next(itNeg), 0);.
4. Вставить ноль перед последним положительным. Для перехода от обратного итератора к обычному используем (++rPos).base(): L.insert((++rPos).base(), 0);.

## Задача 14. Копирование положительных элементов из второй половины

### Текст задачи

Дан вектор V с четным количеством элементов.
Решить для него задачу 6.13 (скопировать в начало все положительные элементы из второй половины).
Поскольку операция вставки в начало вектора делает все его итераторы недействительными, для решения задачи использовать вспомогательный вектор V0.
Инициализировать вектор V0 второй половиной элементов вектора V, после чего применить алгоритм remove_copy_if, используя вектор V0 как источник, а вектор V как приемник данных.

### Алгоритм решения

1. Найти середину вектора V с помощью std::advance.
2. Создать вспомогательный вектор V0, скопировав в него вторую половину: std::vector<int> v0(mid, V.end());.
3. Применить std::remove_copy_if к V0. Предикат x <= 0 отсеет неподходящие элементы (оставит только положительные).
4. В качестве приемника использовать std::inserter(V, V.begin()), который будет вставлять элементы в начало V, сохраняя их исходный порядок.
