# Задание 1.
## Задача 3, 2

### Текст задачи

Имена.
Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя,
Отчество. Имя может быть приведено к строковому виду, включающему традиционное
представление всех трех параметров: Фамилия Имя Отчество (например “Иванов Иван
Иванович”). Необходимо предусмотреть возможность того, что какой-либо из параметров может
быть не задан, и в этом случае он не учитывается при приведении к текстовому виду.
Необходимо создать следующие имена:
1. Клеопатра
2. Пушкин Александр Сергеевич
3. Маяковский Владимир

Обратите внимание, что при выводе на экран, не заданные параметры никак не участвуют в
образовании строки.
Человек.
Создайте сущность Человек, которая описывается:
  Имя: строка
  Рост: целое число
Может возвращать текстовое представление вида “Name, рост: height”, где Name и height это
переменная с именем и ростом.
Необходимо создать и вывести на экран следующих людей:
1. Человек с именем “Клеопатра” и ростом 152
2. Человек с именем “Пушкин ” и ростом 167
3. Человек с именем “Владимир ” и ростом 189

### Алгоритм решения

1. Реализовать класс Name с приватными строковыми полями для имени, фамилии и отчества.
2. В методе toString() класса Name использовать проверки (!empty()), чтобы закидывать в итоговую строку только заданные параметры, отрезая последний лишний пробел методом pop_back().
3. Реализовать класс Person с полями имени и роста. Инициализировать поля строго через список инициализации конструктора (: name(name), height(height)).
4. Для вывода данных реализовать константные методы print(), которые вызывают внутренние методы форматирования строк и направляют результат в поток std::cout.

### Текст задачи

Сотрудники и отделы.
Создайте сущность Сотрудник, которая описывается именем (в строковой форме) и отделом, в
котором сотрудник работает, причем у каждого отдела есть название и начальник, который
также является Сотрудником. Сотрудник может быть приведен к текстовой форме вида: “Имя
работает в отделе Название, начальник которого Имя”. В случае если сотрудник является
руководителем отдела, то текстовая форма должна быть “Имя начальник отдела Название”.
Необходимо выполнить следующие задачи:
1. Создать Сотрудников Петрова, Козлова, Сидорова работающих в отделе IT.
2. Сделать Козлова начальником IT отдела.
3. Вывести на экран текстовое представление всех трех Сотрудников (у всех троих должен
оказаться один и тот же отдел и начальник).

### Алгоритм решения

1. Использовать предварительное объявление (forward declaration) class Department; в заголовочном файле Employee.h, чтобы избежать ошибки циклической зависимости при линковке заголовочных файлов.
2. В классе Department создать вектор указателей std::vector<Employee*> для хранения сотрудников и указатель Employee* manager для назначения начальника.
3. В методе addEmployee класса Department добавлять переданный указатель в вектор и одновременно вызывать метод setDepartment(this) у сотрудника, прокидывая указатель на текущий объект.
4. В методе print() класса Employee реализовать логику вывода, которая сравнивает указатель начальника отдела с указателем this, чтобы корректно определять, является ли текущий сотрудник руководителем.

# Задание 5.
## Задача 1

### Текст задачи

Пистолет стреляет.
1. Создайте сущность Пистолет, которая описывается следующим образом:
2. Имеет Количество патронов (целое число)
3. Может быть создан с указанием начального количества патронов
4. Может быть создан без указания начального количества патронов, в этом случае он
изначально заряжен пятью патронами.
5. Может Стрелять, что приводит к выводу на экран текста “Бах!” в том случае, если
количество патронов больше нуля, иначе делает “Клац!”. После каждого выстрела (когда
вывелся “Бах!”) количество патронов уменьшается на один.
Создайте пистолет с тремя патронами и выстрелите из него пять раз.

### Алгоритм решения

1. Создать класс Gun с инкапсулированным (приватным) целочисленным полем ammo.
2. Написать конструктор по умолчанию Gun(), инициализирующий ammo значением 5 через список инициализации,
и перегруженный конструктор explicit Gun(int ammo) для кастомного количества патронов.
3. Реализовать метод shoot(), в котором оператор ветвления if (ammo > 0) проверяет состояние боезапаса.
4. При успешном выстреле выводить звук в консоль и использовать префиксный декремент --ammo для уменьшения счетчика патронов, так как он отрабатывает эффективнее постфиксного.
